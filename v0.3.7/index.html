DataAugmentation.jl

Efficient, composable data augmentation for machine and deep learning, with support for n-dimensional images, categorical masks, keypoints, and bounding boxes.

An Item wraps data, and a Transform operates on the item. To resize an Image, create a CenterResizeCrop transform and call it on the item.

item = Image(image)
tfm = CenterResizeCrop((128, 128))
tfm(item)

For the most part, the transformations themselves are not very complex. The challenge this library tackles is to reconcile an easy-to-use, composable interface with performant execution; the Design page explains how.

At the moment, the library focuses on spatial data (images, keypoints and masks), and also supports rows of tabular data. The extensible abstractions should fit other domains as well.

Installation

using Pkg
Pkg.add("DataAugmentation")
